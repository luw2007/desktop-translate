## 用户目标

把当前 cmux 专用阅读层升级为通用桌面翻译工具，类似截图翻译：识别桌面中的目标软件，优先加载该软件插件；没有插件时使用 OCR，在原文字位置显示译文。再次按快捷键或 Esc 完整恢复显示。

对应请求条目 1、2。终端专用插件见产品变更 002。两项变更共用已有的本机/pi 可选翻译后端和可配置快捷键。
