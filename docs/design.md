## 当前契约摘要（2026-10-21 文档整理）

本摘要统一下文先后追加条款的优先级，仅核对源码与已记录决定，**不是新增构建、运行或验收证据**。下文 S0–S7 是历史实施切片，未完成门槛仍保留，不是本次整理生成的待办。原始审查 verdict 不改写。用户操作见[项目说明](../README.md)，贡献与命令见[开发指南](../app/README.md)。

- **目标与窗口顺序**：`DesktopCapture.swift` 以精确前台 PID、CGWindowList 前到后顺序锁定最上层普通窗口，绑定 windowID/frame/显示器；同 app 重叠或同 frame 窗口不再一律拒绝。顶层半透明叠住同 app 下层、缺失/重复顺序证据仍拒绝，不切换窗口或整屏兜底。此条取代早期 overlapping fail-closed 的一刀切表述。
- **文字范围**：`Segments.swift` / `DesktopPlan` 处理所有识别到且未高置信度完全处于目标语言的自然语言，包括单词 UI 标签、标题和短片段，不再按 ASCII/英文或正文长度限制。代码、命令、技术标识符和嵌入的技术片段保护规则仍存在；空/符号/数字/纯路径/URL/哈希与目标语言可跳过。早期 ASCII-only 或终端正文限定只保留为历史。
- **绘制与溢出**：`OverlayTextLayout` / `OverlayItem` 首先使用源区域与已确认空白扩展；用户批准的兜底先窄体再缩至最低 9pt（S），仍放不下时可用约 85% 不透明背景覆盖（V），可能盖住邻近未译/受保护内容，但限制在窗口/选区内且不叠画译文。仍不可绘制时保留标记/全文展开。此条取代早期“始终 ≥12pt / 绝不覆盖邻居 / 冲突不标记”的绝对保证；四类结果统计与 S/V 子类不是精度证据。
- **新鲜度与输入**：`DesktopSession.swift` 展示前继续核对目标与内容；成功展示后改用无内容基线的监视器，仅检查身份、frame、Space、屏幕、遮挡与前台变化，不再因底层内容或光标变化撤除。旧译文可能过期，用户关闭后重触发。HUD 约 1.5 秒收起为可拖动图标；屏障保持 key，Esc/快捷键关闭。非激活不承诺零 FocusLost，真实输入/逐终端证据仍缺；早期持续内容监视与光标消抖条款不描述展示后行为。
- **后端与语言**：`TranslationSettings.swift` 支持显式源/目标语言；无文件默认 auto→zh-Hans，旧文件无语言字段保留 en→zh-Hans。本机语言包准备独立于捕获。pi 模型来自实际可用列表；默认 `ocr-text` 发送待译正文，只有显式 `image` 才发送完整选区裁剪。图像位置来自模型自报，不冒充 OCR/native 几何，不存在模式/模型静默回退。
- **隐私与导出**：精确窗口/选区与实际 SCK 结果是边界；sharing=0/.none 不作为保护、安全或捕获条件。OCR 无法保证排除安全控件或敏感像素。默认截图/文字内存持有，但显式调试 JSON 导出会保存原文、译文、保护片段和诊断几何；这取代历史无条件“不持久化文字”说法，不能将导出当匿名报告。`DebugExport.swift` 按白名单排除凭据、环境、可执行路径和整个配置；保存前关闭覆盖层。
- **能力与发布状态**：五终端目前 window-only partial/unsupported + OCR，native 探针无已证明 positioned mapping。原始 S2/S3/S4/S6、001/002 完整验收仍未通过，稳定 production 签名仍是正式应用发行门槛。项目采用 [MIT 许可证](../LICENSE)，许可不代表产品验收通过。
- **设置入口**：菜单栏统一为“设置…”入口，窗口标题“设置”；“通用”区显示快捷键和“更改…”按钮，以及“显示识别区域”复选框，下方为翻译后端设置。快捷键/调试独立保存，调试更改在下次翻译生效；早期单独快捷键设置或调试菜单入口已被替代。
