## 5. 坐标与证据

overlay 全部 window-local 点，截图边界才用 pixel。显式 `ignoreShadowsSingleWindow`、关闭 `scalesToFit`；输出宽高=sourceRect×pointPixelScale，CGImage 偏差>1px 拒绝，避免阴影/letterbox 偏移。跨屏窗口一个 backing scale，按实际图片尺寸分别计算 sx/sy，不猜固定 2x。

Vision (x,y,w,h) → pixel (xW,(1-y-h)H,wW,hH) → 除 sx/sy 加 crop Quartz 原点 → 减窗口原点得 local；AppKit 全局转换统一用主显示器桌面高度翻 y，保留负坐标，不逐屏翻转。框裁剪选区/父布局，字体边距均点。

独立公开 fixture 进程在已知 frame 绘制已知文字，不能由被排除的本 app 作截图基准；角点/round-trip 数学误差≤1pt，真实 OCR 框≤4pt，第三方应用人工标注独立报告。目前两台显示器均 2x（4608×2592、逻辑2304×1296），无实际 1x 证据；验收切非 HiDPI 或虚拟 1x，副屏摆左/上形成负坐标。跨屏与“显示器具有单独空间”开/关各记录真实裁剪行为；不能获得完整可见选区就明确拒绝而非通过。

## 6. 覆盖、输入、分段与溢出

选择/HUD/overlay/展开统一 non-activating NSPanel，可成为 key，不调用 NSApp.activate，保持 `fullScreenAuxiliary`。真实 FocusLost 与输入屏障仍未测；五终端必须用公开 DECSET-1004 记录程序测选择→展示→关闭 focus-out 并披露实际次数与限制，零不是验收要求，不能把未测写为零。当前不引入 speculative CGEventTap；任何新增输入监控/AX 权限路线须更新权限矩阵并重新提交 Opus 复审。

必须有透明全目标窗口 frame 事件屏障，ignoresMouseEvents=false，吞点击/滚轮/手势与非关闭键，不仅遮罩文字块；Esc/快捷键关闭。窗口外不拦截，用户点击外部导致前台变化撤除，不能承诺窗口外无操作。HUD 位于选区外侧/边缘同一屏，承载可见 `.translationTask` host、来源/provider/进度/警告/关闭提示；展开面板共用宿主。语言包准备使用独立可激活设置窗口而非捕获 HUD；已开始的捕获一旦目标失效不显示旧结果。

只在 TextRegion 遮罩/译文，不整窗铺白，不遮图标或邻居。字号≥12pt，测量换行并用父裁剪/占用图约束；空间不足明确标记，可展开完整可滚动译文与保护片段，共用 region ID，不静默截断或扩张。每个译文区域恰好产出一个条目并带一个如实结果：已绘制、空间不足（仅橙色标记，不覆盖原文）、与相邻文字冲突（不覆盖也不标记）、无可用原文位置（不绘制）；任何情况都不丢弃条目，全文始终可经展开面板读取。HUD 按这四类计数并只在未全部绘制时提示展开；没有任何区域实际绘制时 HUD 报失败而不是成功。

段落与二维溢出：OCR 正文可将连续、均可翻译、左缘/高度/行距一致的行合并为段落单元；受保护行、遗漏观察、间隙内的识别矩形或几何不一致阻断合并，终端保守分段不变。段落请求整块翻译，并使用 image renderedWhole 同样的保护片段逐字校验；绘制区域含源行和块内行间隙，允许输出行数改变。单行或段落放不下时，可向右及向下延伸到已证明空白：距任何识别矩形至少 4pt，受窗口、精确选区、父容器约束；同一张持有原图逐列/逐行检查与采样背景各通道差≤12，遇首个不符即止。绘制时重新夹紧几何，拒绝碰撞；源块和全部可绘制扩展条带纳入同一个不可变原图基线，不重采或扩大捕获。拟合与绘制共用 OverlayTextLayout，保持至少 12pt；仍放不下就 fitOverflow，原文不覆盖、橙色标记、展开保留全文。HUD/log 分别统计向右、向下扩展；调试 E 表示任一已绘制扩展，绘制语义不变。

溢出兜底（2026-10-19，用户明确选择，取代此前“绝不覆盖邻近内容”规则，仅限此情形；上文“至少 12pt/fitOverflow”按本段更新）：译文在源区域加已证明空白处仍放不下时，依次：（1）窄体（SFNS Condensed，宽度 trait -0.2，字距 -3%）同字号重试，仍放不下则字号自 12pt 逐级降至 9pt 下限（保持窄体），仍只绘制在源区域+已证明空白处，拟合与绘制共用同一 OverlayTextLayout，调试码 S；（2）最后手段：半透明覆盖（调试码 V）——12pt 窄体，从源行包围盒左上角先向右（至同行最近障碍或窗口/选区边界）再向下增长，背景取自源行采样色，约 85% 不透明（被盖内容隐约可见），带细边框以示为覆盖；允许盖住未翻译、受保护或相邻文字/图标，但绝不与其他译文条目的源/扩展区域或已放置的覆盖重叠（冲突则仍为空间不足橙色标记），也不越出窗口/选区。新鲜度基线只含源块与已证明扩展条带，覆盖多出的区域不入基线、不重采或扩大（其下内容经半透明可见）。仍无法显示者才是 fitOverflow（橙色标记+展开面板）。HUD/log 分别统计窄体/缩小与覆盖。

重叠项与K子原因（2026-10-19）：见[开发历史](development-history-evidence.md#集中验证)同日条目。碰撞按阅读序裁剪（`OverlayOccupancy.subtract`，≥6pt），无法裁剪者为 C 并画标记；`Segments.swift` 的 `SkipReason` 记录触发规则，日志仅输出计数。

分段不以正文/长度/源语言作为门槛：所有识别的自然语言文字（包括 UI 单词、标签、标题、状态）只要未高置信度完全处于目标语言就翻译。K 仅为空、符号、数字/时间/单位、纯 URL/路径/哈希或目标语言（`target`）；纯 snake_case/camelCase/dotted 标识符计入 P（`identifier`），代码/命令仍保护，嵌入技术片段原样保留。目标语言判定使用脚本证据与保守的 NaturalLanguage 置信度，模糊情形继续翻译。软换行合并段落请求，保留各行矩形并集排版；不跨 pane/按钮/单元合并。ID 为 region/piece 命名空间，沿用结果完整性校验。终端非 ASCII 列宽必须终端报告或 OCR 对齐，否则转明确 OCR；不能自己按字符数推列宽。

显式调试 JSON：只在图例按钮点击时冻结当前会话 DTO，包含文本、译文、诊断几何和无密钥设置；不影响计划/绘制，不自动保存，不写文本日志。图例本体穿透鼠标，按钮独立的非 key/nonactivating panel 仅接收自身范围点击。导出先关闭覆盖层与监控，再 NSSavePanel 选址（默认桌面），避免保存面板激活与覆盖层 key/新鲜度监控互相干扰；取消也保持关闭。未被保留的观察文字/置信度及未知碰撞伙伴以缺失值表示，不伪造证据。

源语言残留（2026-10-20）：目标语言为英文（`en`/`en-*`，大小写不敏感）时，已绘制条目的译文若仍有超过 30% 的字母是 CJK（汉字/假名/谚文），且该区域捕获原文本身含 CJK 字母，则调试分类从 T/E/S/V 改为 **R** 并带子原因 `source-language-residue`（`R` 原义“已规划无译文”保留，图例标签与导出 JSON 的 `subreason` 都显示该子原因）。判定不读配置的源语言，`auto` 与固定源语言一致；英文原文永不触发。这是纯诊断：计划、绘制、遮罩、保护、新鲜度与 HUD 四类计数全部不变，条目仍计入已绘制；未保留文字/几何之外的信息，日志只追加一行「译文仍含源语言字符：N 个区域」的计数，不含原文或译文。
